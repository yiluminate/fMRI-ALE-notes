# Research Protocol Template

[Templates](README.md) · [Related chapter](../docs/01-foci-extraction.md)

## Basic Information

- Project title: to be completed.
- Date and responsible investigator: to be completed.
- Research question: to be completed.
- Population, task/process, baseline, and target direction: to be completed.
- Primary analysis: to be completed.
- Secondary analyses/subgroups/comparisons: to be completed, with justification.
- Registration plans and location of the registration or public record: to be completed or not applicable.

## Search Plan

| Database/supplementary source | Complete search strategy or method | Date range/other restrictions | Actual search date |
| --- | --- | --- | --- |
| To be completed | To be completed | To be completed | To be completed |

- Deduplication criteria and tools: to be completed.
- Title/abstract and full-text reviewers, and disagreement resolution: to be completed.
- Location of exclusion records and screening-flow counts: to be completed.

## Grouping and Analysis Plan

- Definition of the final independent unit: to be completed.
- Selection or combination of related contrasts from the same sample: to be completed.
- Handling of opposite directions: to be completed.
- Expected number of independent units and limitations for each primary analysis/subgroup: to be completed.
- Target space, transformation method, and mask: to be completed.
- Single-dataset correction method, cluster-forming threshold, cluster-level threshold, and permutation count: to be completed, with supporting sources.
- Inputs and separate parameters for pooled/conjunction/contrast analyses: to be completed or not applicable.
- Purpose, scope, and comparison strategy for sensitivity analyses: to be completed.
- Reporting of analyses with no significant clusters, failed runs, and missing information: to be completed.

See [Chapter 03](../docs/03-ale-analysis.md) for parameter selection.
